# Migration Program Overview (SAMPLE DATA — fictional, for demo only)

The modernization program today covers assess, plan and migrate phases for on-premises customers. Engagement formally ends at cutover, after which customers are handed off without a structured day-2 operations plan or guidance.

Field members report that IT administrators and application developers lack direction after migration. There is no funded post-migration consultation service in the current program.

Engineering assessment: an MVP of a post-migration guidance experience could reuse the existing advisory recommendations engine and the monitoring baseline templates. The estimated engineering effort is 2 squads for 2 quarters, versus 5 squads if built from scratch.

Competitive analysis: two major competitors bundle 90-day post-migration "operate" packages with their migration offers, and analysts cite day-2 operations as a top differentiator in competitive deals lost in the last fiscal year.
